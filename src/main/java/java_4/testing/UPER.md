<h1>The Problem Solving Framework : 'UPER'</h1>

* U = "Understand"
* P = "Plan"
* E = "Execute"
* R = "Reflect" / "Refactor"

<h2>1. Understanding the Problem</h2>
* Sales Tax App created by using TDD

* Practice knowledge of pillars of OOP in class hierarchy

* App calculates sales tax of goods

* Basic sales tax is 10% on all good except books, food, and medical products

* Import duty is additional sales tax on ALL imported good at 5% rate

*Customer purchasing items get receipt that lists
    <li>Name of all the items and their price (w/ tax)</li>
    <li>Total cost of the items</li>
    <li>Total amounts of sales taxes paid</li>

* Rounding rules: Tax rate n%, shelf price p
* Contains np/100 rounded up to nearest 0.05
<h2>
